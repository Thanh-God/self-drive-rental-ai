# Approved KDrive canvas design system
Reference project: 2a8ac76a-2f37-4542-b2c1-bfefb9c1ca0d; source draft f9aad8bd-e9b0-457d-9fd1-219b60ed8bef v1.
Desktop only, 1440px canvas, comfortable centered 1280px content. Preserve source draft identity and visual language: muted warm gray #E4E0D8 with card/input surfaces #EEEBE4, charcoal #1A1A1A, warm orange #FF7E33 and amber #F59E0B; General Sans body and Gambetta serif headings, with Vietnamese-capable fallback. Generous whitespace, rounded large photographic cards, restrained motion, clear keyboard focus. Same navbar/footer and KDrive wordmark treatment as source draft. The original teal source CSS is implementation context, not a competing redesign theme.
All copy Vietnamese; VND integer amounts; rental priced per 24h block; display time Asia/Ho_Chi_Minh. No online payment, mobile key, insurance guarantees, awards, fabricated reviews, AI/Map active features or new business actions. ACTIVE means Đang khai thác, not guaranteed availability. Server quote validates dates, branches, route and price.
Design-only extension, not production implementation. Gallery is planned C10B; imagery is illustrative in draft, not verified fleet photography. Do not claim stock image rights are verified. Show plain text credit area. No modifications to backend contracts or database.
Required three pages: vehicle list with current filter set; vehicle detail with proposed gallery, current amenities/reviews and quote CTA; own booking list with current statuses, dates, branches and total plus detail links. Detail CTA continues to /user/bookings/new?vehicleId=..., where dates/branches and quote are handled; do not imply booking is confirmed by clicking CTA. Represent loading/empty/error/retry as small designed states without extra pages. Reuse shared components across all three.
Use ONLY the fonts, colors, spacing, and component styles defined here and the selected source draft. Do not introduce unrelated colors/fonts/visual styles.
