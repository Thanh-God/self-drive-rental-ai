5. CÁCH TÍNH NĂNG HOẠT ĐỘNG

Admin đăng nhập qua JWT hiện có -> mở /admin/locations trong API mode -> UI gọi API Admin đọc phân loại và địa điểm -> backend kiểm tra ADMIN -> service kiểm tra nghiệp vụ -> repository đọc MySQL -> DTO trả về -> UI hiện loading/empty/error/data tương ứng.

Tạo địa điểm:
Admin chọn phân loại thật, nhập tên/vĩ độ/kinh độ/trạng thái -> frontend kiểm tra dữ liệu cơ bản -> gửi POST JSON -> backend validate lại toàn bộ, kiểm tra category tồn tại và quyền -> transaction ghi locations -> trả ID/DTO -> UI hiển thị kết quả, GET đọc lại và reload trang vẫn còn dữ liệu. Backend là nơi quyết định tính hợp lệ; UI không thay lỗi API bằng demo.

Sửa địa điểm:
Admin chọn bản ghi thật -> form được điền bằng API -> gửi PUT theo ID -> validate -> transaction cập nhật đúng bản ghi -> GET/reload chứng minh dữ liệu mới. Sửa location không tự thay snapshot itinerary_items, không sửa dữ liệu thuê xe hay branch.

Trạng thái không hoạt động:
Dùng trạng thái hợp lệ đã thống nhất cho catalog, dự kiến ACTIVE/INACTIVE theo thiết kế/demo hiện có. INACTIVE không phải xóa cứng, không tự xóa FK/snapshot/hành trình cũ, không tự đổi lịch xe. Nếu tài liệu/source có contract trạng thái khác, đối chiếu và ghi quyết định trước triển khai, không thêm ARCHIVED/DELETED tùy ý.

Phân loại:
location_categories đã có bảng với name UNIQUE. Cần API đọc danh sách và khả năng Admin tạo phân loại để catalog mới có dữ liệu thật, không chỉ các tên hardcode trong demo. Chỉ triển khai list/create trong phạm vi đầu tiên; đổi tên/xóa phân loại và retention chưa được giao.

Không có tải bản đồ hoặc định vị GPS. Tọa độ là hai giá trị số được validate, không chứng minh địa điểm có thật, tính tuyến chính xác hoặc được Map provider xác nhận. Không bịa dữ liệu tham quan; fixture dùng dữ liệu mẫu ghi rõ. Dữ liệu thật nếu muốn đưa vào sản phẩm cần nguồn và attribution phù hợp, là việc khác.

6. CONTRACT API ĐỀ XUẤT CỤ THỂ

Tất cả endpoint dưới /api/v1/admin/ để tận dụng guard ADMIN hiện có, không sửa SecurityConfig để public API:

    GET  /api/v1/admin/location-categories
    POST /api/v1/admin/location-categories
    GET  /api/v1/admin/locations
    GET  /api/v1/admin/locations/{id}
    POST /api/v1/admin/locations
    PUT  /api/v1/admin/locations/{id}

Không endpoint DELETE. Không endpoint Guest, AI hoặc itinerary trong scope.

Category DTO tối thiểu: {id, name}.
Create category input: {name}; trim đầu/cuối, required, độ dài theo schema (100), duplicate name -> 409 theo unique thật của DB. Không tự đổi collation hay bổ sung uniqueness khác ngoài schema. Quy tắc chữ hoa/thường kiểm theo DB/source thực và ghi rõ.

Location DTO tối thiểu: {id, categoryId, name, latitude, longitude, status}.
Input gồm categoryId/name/latitude/longitude/status; ID do backend cấp. Dùng BigDecimal hoặc cách biểu diễn phù hợp DECIMAL(10,7), không so tọa độ bằng chuỗi hoặc tự truncate ngoài contract.
- name required, trim, tối đa200 ký tự.
- categoryId required và phải tồn tại.
- latitude bắt buộc, trong [-90,90], longitude bắt buộc trong [-180,180], gồm cả biên.
- Không chấp nhận NaN, Infinity, null, chuỗi không phải số hay độ chính xác không phù hợp mà silently làm lệch tọa độ.
- status chỉ thuộc contract đã chốt, không nhận chuỗi tùy ý.

HTTP: read/update nonexistent ->404; input sai ->400; duplicate category ->409; chưa đăng nhập ->401; USER/STAFF ->403; thành công theo convention được chọn và ghi rõ (khuyến nghị create201, update200). Kiểm cả lỗi parse JSON, số vượt phạm vi, FK và profile quyền, tránh trả500 cho input sai.

Không suy ra tên địa điểm UNIQUE: schema hiện không quy định như vậy. Không tự cấm hai địa điểm cùng tên. Nếu cần uniqueness mới, ghi câu hỏi chứ không tự tạo policy.

Bảng locations hiện chưa có cột version; không thêm @Version trỏ vào cột không tồn tại hoặc giả định PUT đã chống lost-update. Trong lát cắt này không tuyên bố kiểm chứng concurrency/version khi chưa có contract và schema tương ứng. Nếu phát hiện cần mở rộng version/migration để đạt yêu cầu mới, ghi riêng checkpoint/đề xuất cho Codex A; không sửa migration V1/V2 đã phát hành hay tự tạo schema song song.
